# Tone is read by local heuristics; model tone is opt-in

The pet reads the owner's tone (happy, angry, sad, neutral) from what they type with local heuristics: words, capitals, repeated punctuation, emoji. This is free, instant and private, and it is fine for it to be wrong now and then. A setting lets the owner turn on model tone, which asks a small model per submitted prompt; it is off by default because every call is billed to the owner's session and adds a delay to the reaction.
